# Matchup 1 — Sourced Model Candidates

**Methodology (current):** This matchup is personal-use-only (see `docs/PROJECT-SPEC.md`'s Licensing Strategy section) — Marvel characters can't legally be sold under any license, so redistribution terms (CC BY vs Standard vs ND) don't matter here. The only real bar is **legally downloadable and genuinely detailed**: a full sculpted statue in a dynamic pose, not a bust, mini, Lego-style figure, or Funko-style toy. Every candidate below was verified by actually downloading and viewing its thumbnail — not just trusting a title or license badge, which is how earlier passes got fooled by Lego-minifigure-style results.

AI-generated origin is a lower-priority fallback signal now, not an automatic reject (nothing here is being redistributed) — but a genuinely AI-generated piece is still ranked below a real sculpt when both exist.

## Dropped from consideration entirely

- **Jean Grey, Iceman, Storm** — all three had real detailed sculpts available, but every one was licensed CC BY-NC-**ND** (No Derivatives), which was disqualifying back when this list was being built for potential public redistribution. Now that this matchup is confirmed personal-use-only, ND licensing isn't actually a blocker anymore — **these three are worth reconsidering** if a future gap needs filling, since the quality bar (not the license) was never the problem for them.
- **Psylocke** — every candidate found was either paid-only or the wrong format (a Hueforge 2.5D color-relief print, not an actual sculptable bust).
- **Bishop, Cable** *(original Bishop-role picks before the restructure)* — Cable came back into the roster after re-checking with the corrected statue-quality bar; Bishop (the character) still has nothing.
- **Scarlet Witch, Polaris, Avalanche** — Scarlet Witch's only candidate was a rough/messy test print (replaced by Quicksilver); Polaris and Avalanche never had real candidates.
- **UncleKam's "X-Men Busts Part 2"** and **chibiprinters' Havok** — both explicitly AI-generated (Bing Image Creator via MakerWorld's Image-to-3D tool for the former), deprioritized without a full visual review even under the relaxed AI standard, since better alternatives existed for every character they covered except Havok.

## Automated verification tooling

`scripts/check-license.sh <url>` still works for checking MakerWorld/MyMiniFactory/Thingiverse license text automatically (useful if a *public* matchup ever needs it), but for this personal-use matchup the actual bottleneck is visual quality, which has to be checked by downloading and viewing each candidate's thumbnail — see the pattern used throughout this document (`curl` with a browser User-Agent, extract `cover`/`thumbnail` URLs from the embedded JSON, download, view).
